OpenFrame-5F FreeCAD

This repository contains my FreeCAD recreation of the OpenDrone OpenFrame-5F.

The goal is to recreate the original frame in FreeCAD while making the model structure and sketches editable, understandable and suitable for further development.

Project status

The model is a work in progress. Approximately 95% of the frame has been recreated to match the original design.

Some parts still have modelling differences or unresolved issues due to the challenges of recreating the original geometry in FreeCAD.

I am developing this project in my free time as an independent contribution to the OpenDrone community.
